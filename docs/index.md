# Gardience Provider

[Gardience](https://gardience.com) is a supported console for Windows and Linux machines on open-source
[Salt](https://saltproject.io): patching, a scored STIG/CIS-aligned baseline, drift repair, event-driven
automation, two-person approval and a tamper-evident audit log.

With this provider, Terraform builds the machine and Gardience takes over from its first boot:

1. `gardience_enrollment` gives a first-boot script for the machine's `user_data`. The machine installs the
   pinned, hash-checked Salt agent and joins without anyone approving it.
2. A `gardience_event_rule` of kind `join` applies a saved state (`gardience_state`) to it the moment it joins.
3. `gardience_machine` waits until it has joined, and removes it from the fleet on `terraform destroy`.

Every change the provider makes is recorded in Gardience's audit log under the API key's owner.

## Authentication

The provider uses a Gardience **configure** API key. An admin creates one in **Settings > API keys** with the
scope **Configure (Terraform, admins)**. Configure keys manage configuration and remove machines; they never run
anything on the fleet. Requires Gardience 1.5.0 or later.

```terraform
terraform {
  required_providers {
    gardience = {
      source = "gardience/gardience"
    }
  }
}

# The address and a configure key (an admin makes one in Settings > API keys).
# Prefer the GARDIENCE_URL and GARDIENCE_API_KEY environment variables over writing them here.
provider "gardience" {
  url = "https://gardience.example.com"
}
```

## Schema

### Optional

- `api_key` (String, Sensitive) A Gardience configure key (`gdn_...`). Defaults to the `GARDIENCE_API_KEY` environment variable.
- `ca_cert_file` (String) PEM file with the certificate authority that signed the server's certificate, for a private CA. Defaults to `GARDIENCE_CA_CERT_FILE`.
- `insecure` (Boolean) Skip certificate checks. Only for a lab with a self-signed certificate.
- `url` (String) Address of the Gardience server, for example `https://gardience.example.com`. Defaults to the `GARDIENCE_URL` environment variable.

## Example: web servers that configure themselves

```terraform
# Three web servers on AWS that join Gardience, get their baseline on first boot, and leave the fleet on destroy.
terraform {
  required_providers {
    gardience = { source = "gardience/gardience" }
    aws       = { source = "hashicorp/aws" }
  }
}

provider "gardience" {} # GARDIENCE_URL and GARDIENCE_API_KEY
provider "aws" { region = "us-east-1" }

variable "ami" { description = "An Ubuntu 24.04 or RHEL 9 image" }

resource "gardience_enrollment" "web" {
  label  = "web tier"
  hours  = 2160
  groups = ["web"]
}

resource "gardience_state" "web_base" {
  name    = "web_base"
  content = <<-YAML
    nginx:
      pkg.installed: []
      service.running:
        - enable: True
        - require:
          - pkg: nginx
  YAML
}

resource "gardience_event_rule" "web_join" {
  id         = "web-join"
  kind       = "join"
  scope      = "group"
  group      = "web"
  state      = gardience_state.web_base.name
  depends_on = [gardience_enrollment.web]
}

resource "gardience_event_rule" "keep_nginx" {
  id      = "keep-nginx"
  kind    = "service"
  os      = "linux"
  service = "nginx"
}

data "gardience_bootstrap_script" "web" {
  count         = 3
  enrollment_id = gardience_enrollment.web.id
  os            = "linux"
  node          = "web-${count.index + 1}"
}

resource "aws_instance" "web" {
  count         = 3
  ami           = var.ami
  instance_type = "t3.small"
  user_data     = data.gardience_bootstrap_script.web[count.index].content
  tags          = { Name = "web-${count.index + 1}" }
}

resource "gardience_machine" "web" {
  count      = 3
  name       = "web-${count.index + 1}"
  depends_on = [aws_instance.web, gardience_event_rule.web_join]
}
```
